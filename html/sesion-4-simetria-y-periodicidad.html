Sesión 4: Simetría y periodicidad

Simetrías

En una función se distinguen dos tipos de simetrías:

  • Función simétrica respecto del eje Y, cuando f(-x)=f(x). Este tipo de función se llama función par.
  • Función simétrica respecto del origen, cuando f(-x)=-f(x). Este tipo de función se llama función impar.

                       

             


Periodicidad

Una función es periódica cuando los valores de f(x) se repiten cada cierto intervalo.

                                         f(x)=f(x+T)=f(x+2T)=...=f(x+kT)

La amplitud, T, del intervalo es el periodo, con k un número entero.
