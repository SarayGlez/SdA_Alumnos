Sesión 2: Dominio y recorrido

Definiciones

  • El dominio de una función f(x),Dom f , es el conjunto de todos los valores que toma la variable independiente.
  • El recorrido o imagen de una función f(x), Img f, es el conjunto de todos los valores que toma la variable dependiente.

¿Cómo calcular el dominio de una función dependiendo del tipo de esta?

  • Función polinómica: están definidas para todos los números reales.
  • Función racional: no están definidas para los valores de x que anulan el denominador.
  • Función radical de índice par: sólo están definidas para los valores de x que hacen el radicando mayor o igual a cero.
